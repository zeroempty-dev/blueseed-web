# ZeroEmpty

Digital freight marketplace landing page — connects businesses and truck owners, eliminates broker dependency, reduces empty return trips. Built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:5173

## Build for production

```bash
npm run build
```

Output goes to the `dist/` folder.

## Preview production build

```bash
npm run preview
```

## Project structure
